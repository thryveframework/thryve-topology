# Security Policy

## Supported Versions

Only the latest released version is supported with security fixes.

## Reporting a Vulnerability

If you find a security issue in this viewer (for example, something in how it
parses a `topology_export.ron` file that could lead to a crash, memory-safety
issue, or unexpected code execution), please **do not open a public issue**.

Instead, report it privately via [GitHub Security Advisories](https://github.com/thryveframework/ThryveVisualization/security/advisories/new) for this repository. Include:

- A description of the issue and its potential impact.
- Steps to reproduce, and a minimal `topology_export.ron` file if relevant.
- The version/commit you tested against.

We'll acknowledge reports as soon as possible and follow up with a fix and,
where appropriate, a coordinated disclosure timeline.
